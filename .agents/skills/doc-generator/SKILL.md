# Technical Document Generator

## Use this skill when:
- The user asks to document functions, classes, or code modules.
- The user requests an export to Google Docs or a .docx file.

## Instructions:
1. Parse the requested code files to map architecture, functions, parameters, and return types.
2. Structure the parsed details into a clean JSON layout.
3. Automatically leverage an ecosystem tool or local file-builder script to format this payload into Google Docs format or a local MS Word (.docx) file based on user preference.
